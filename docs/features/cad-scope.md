## Functional gaps, distinct from pending execution evidence

- **Editable brief:** assumptions can be refined through the accepted model's normal Edit workflow. There is no editable structured pre-build brief form; clarification accepts an answer to the pending question.
- **Source context:** semantic selected objects and the first explicitly selected image use the existing context builder and backend image adapter. The initial review incorrectly reported missing image wiring; tracing `buildContext` and four focused passing tests corrected that finding. Real-model image interpretation remains unverified. Full source documents, repositories and inaccessible files are not implicitly ingested.
- **Copied model editing:** detached snapshots deliberately cannot mutate original jobs. Adopting copied source into a new editable model is unimplemented; existing artifact access remains subject to file-reference authorization.
- **Geometric measurements:** trusted inspection supports exterior XYZ bounds, solid count, volume and presence of a matching circular edge diameter. It does **not** establish hole count/centers/depth, pocket depth, mating clearance, interference, unchanged feature topology or manufacturing suitability. A circular edge is not proof of a through-hole. STEP/GLB revision identity and checksums alone do not establish geometric equivalence.
- **Chat inspection:** no authorized interactive exact-geometry tool is wired to Explain. Metadata or visual inference must not be presented as measured dimensions.
