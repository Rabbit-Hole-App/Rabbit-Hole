Interface component standards

Isolated UI specimens for the controls found in the review screenshots. Shared card surfaces frame blue actions and selection. Warm rust identifies Interactive content or a local experiment, green marks positive status and completion, amber signals warnings, and red marks danger.

Actions and inputs

Use one primary action per decision group. Edit is secondary, Cancel is quiet, and a destructive action uses the danger role.

Button hierarchy

Give the main action the strongest fill. Use outlined buttons for alternatives, quiet buttons for Cancel, and the danger style for a destructive action.

Dropdowns, filters and sorting

Show the active value on a dropdown and use a selected state for filters that can be toggled independently.

Links, pills and shortcuts

Links navigate. Pills carry a type, status or context, and shortcut keys use their own compact treatment.

Skeleton, shimmer and spinnerPreserve the reserved card frame and 18 px radius. Sample skeleton inset 11 px, line height 11 px, radius 5 px and 7 px gaps. Reduced motion uses static placeholders and status text.
ScrollbarKeep one scrolling region per pane and reserve the gutter. WebKit-style width 8 px; thin fallback where native. Transparent track, #C7CEC6 pill thumb, #AAB6AB hover.
LinksInk #375D92, hover #2B4B78, pressed #203858. Underline offset 3 px. Use the standard blue focus outline.
Modal and Trash18 px radius, 1 px #DEDFD8 border, 16 px inset, 460 px maximum width for confirm, up to 92vw and 80vh. Scrim #202723 at 42%, same overlay shadow as menus. Place initial focus on Cancel for destructive confirmation and return it to the opener. Trash list uses Restore and an explicit empty state.
Toast / Sonner recipe355 px maximum width, 16 px viewport inset bottom and right. Each toast uses 10 px radius, 1 px semantic border, 9 × 10 px padding and 8 px gap. Dismiss target 26 px with 13 px icon. Non-error preview toasts expire after 3 s; errors persist for Retry or dismissal. Apply the same recipe to the existing stack or a later Sonner adapter.
Notification and commentsUse the 10 px notice radius and 9 × 10 px inset. Unread #EAF1FB with #426DB2 border and explicit Unread label or count. Read uses the card surface. Use existing Bell, MessageCircle, MessageSquare and Reply glyphs.
