Icon button states

General controls use neutral colors at rest and on hover, then soft blue when pressed or selected. Playback uses soft blue at rest. A filled primary action uses white ink on solid blue. Glyphs inherit the button’s ink.

Exact implementation values

PartValues for this template
Icon-only control35 × 35 px box, 8 px radius, 1 px border, centered glyph. Use the per-icon size in the catalogue.
Icon with label35 px minimum height, 8 px radius, 1 px border, 6 px gap, 10 px horizontal padding. Label 13 px, weight 650, line-height 1.45. Text and icon share currentColor.
Type pillText only, 13 px and weight 700. Minimum height 26 px, radius 999 px, padding 1 px vertical and 11 px horizontal. Explanation uses #EAF1FB / #375D92. Interactive uses #F8ECE3 / #934723.
Reference resize grip26 × 26 px box, 7 px radius, 1 px transparent border at rest. Use card #FFFEFA with ink #5D675F at rest. Hover uses #EAF1FB and press or drag uses #D0E0F4, both with border #ADC4E5 and ink #375D92. Glyph 14 × 14 px, stroke 1.4.
Keyboard focus2 px solid #426DB2, outline offset +2 px. Resize grip offset −2 px.
Feedback and playbackFeedback uses the shared 35 × 35 px icon button with a 13 px glyph. Playback uses the shared labelled button with a 14 px glyph.
SVG paintStroke inherits currentColor. The default fill is none and caps and joins are round. Both feedback glyphs fill with blue ink #375D92 when selected. Enabled surfaces and glyphs are opaque. Disabled controls use 45% opacity.
Accessible namesGive icon-only buttons an aria-label. Put aria-hidden on the icon when its button already supplies the name. Use aria-pressed for toggles and aria-expanded for disclosures.

The resizable card shell supplies the neutral surfaces and type colors. Shared controls use the blue palette for selection, focus, playback and filled primary actions. Warm orange is reserved for the Interactive pill and scene data accents. Runtime links document existing glyphs and their dimensions.
