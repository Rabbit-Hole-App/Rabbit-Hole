# Illustrated Transformer walkthrough

Ten written `/explain` references work through “the cat sat on the mat.” The registry reuses the QKV and encoder reference IDs and adds eight topics. Each reference has Brief, Balanced, and Detailed examples. Its source entry carries the learner prompt, paraphrases, and narrow selector keywords.

All computations use four visible model entries and two entries per head. The corresponding dimensions on the strips are 512 and 256. The toy model uses two heads and a six-word vocabulary. Each source position uses the same shared embeddings, position signals, and projection matrices throughout. The decoder prefix is “the cat sat,” and the vocabulary example predicts “on.” [Shared data](../../../../../packages/web/src/tutor-diagrams/transformer-walkthrough-data.js) · [Original paper](https://arxiv.org/abs/1706.03762) · [Illustrated Transformer](https://jalammar.github.io/illustrated-transformer/)

The worked input for sat is `[1.109, -0.516, 0.72, 1.4]`. Its first-head query is `[1.829, -0.516]`, key `[1.109, 1.4]`, and value `[0.72, 1.4]`. The first head puts 0.650 on cat and returns `[0.362, 1.115]`. The second head puts 0.388 on the first the. The joined output `[0.362, 1.115, 0.316, 0.492]` projects to `[0.339, 1.115, 0.023, 0.246]`. The final probability of on is 0.465. Display rounding keeps each distribution at one.
