The SVG links below are output from the real renderer; the adjacent JSON is the author's semantic reference. A generated card may use different data. Judge its mechanism and calculations against its own data rather than requiring it to copy these numbers.

| Lesson | Natural `/explain` request | Actual reference and what it demonstrates |
| --- | --- | --- |
| 04 | How does a decision tree know whether a split is good? | [Worked impurity gain](references/ml-tree-impurity-gain.svg) · [JSON](references/ml-tree-impurity-gain.json). Parent 4 A / 4 B splits into 3 A / 1 B and 1 A / 3 B. The same counts give weighted Gini 0.375 and decrease 0.125; weighted entropy 0.8113 bits and information gain 0.1887 bits. |
| 05 | What changes when I increase C in an SVM? | [C trade-off](references/ml-svm-c-tradeoff.svg) · [JSON](references/ml-svm-c-tradeoff.json). Matched training data and axes, different soft-margin optima and margin widths. Increasing C does not necessarily change the boundary or improve classification accuracy. |
| 05 | Why can a nonlinear feature map help an SVM separate classes? | [Feature map](references/ml-svm-feature-map.svg) · [JSON](references/ml-svm-feature-map.json). Outer values −2 and 2 versus inner −1 and 1 become separable after adding the squared feature. Stable IDs connect each observation across the transformation. |
| 06 | Why can distance-weighted KNN give a different answer? | [Weighted vote](references/ml-knn-distance-weighted-vote.svg) · [JSON](references/ml-knn-distance-weighted-vote.json). The same three neighbours yield uniform majority A, but inverse-distance totals 5/6 for A and 1 for B change the prediction to B. |
| 06 | Why does scaling one feature change the nearest neighbour? | [Scaled distance](references/ml-knn-scaled-distance.svg) · [JSON](references/ml-knn-scaled-distance.json). Raw sample coordinates remain fixed. Doubling the x-feature scale changes distances from approximately A 4.123 / B 3.162 to A 4.472 / B 6.083, reversing the nearest neighbour. |
| 06 | How does changing K change a KNN decision boundary? | [K-dependent boundaries](references/ml-knn-k-boundaries.svg) · [JSON](references/ml-knn-k-boundaries.json). The same observations give several small regions at K=1 and a simpler majority boundary at K=3; the marked query changes class. |
| 06 | How do KD-tree partitions divide the space when searching? | [Tree and partition regions](references/ml-kd-tree-partitions.svg) · [JSON](references/ml-kd-tree-partitions.json). Numeric split lines match the tree's tests and counts. The highlighted query visits the matching leaf first; exact neighbour search may still backtrack. |
| 07 | What is the difference between the assignment and update steps in K-means? | [Assignment then update](references/ml-kmeans-assignment-update.svg) · [JSON](references/ml-kmeans-assignment-update.json). Assignment uses the starting centres without moving them. Update moves each centre to its assigned group's mean while the observations stay fixed. |
| 07 | How can I tell core, border and noise points apart in DBSCAN? | [Core, border and noise](references/ml-dbscan-core-border-noise.svg) · [JSON](references/ml-dbscan-core-border-noise.json). Explicit radius and minimum count, including self. A border point has too few neighbours to be core but is within the radius of a core point; the noise point is not. |
| 07 | How does a GMM calculate the probability that a point belongs to each cluster? | [GMM responsibilities](references/ml-gmm-responsibilities.svg) · [JSON](references/ml-gmm-responsibilities.json). Equal-prior Gaussian components produce normalized memberships about 0.8808/0.1192, 0.5/0.5 and 0.1192/0.8808. Component density and posterior membership are kept distinct. |
