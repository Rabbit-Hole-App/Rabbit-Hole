# PLT-5 (re-amended): smooth by default (ml-plot-layouts.js)

Rule as built: a line series is smooth unless `series.smooth === false` (then straight segments, as authored): the pre-sprint default `smooth !== false`, restored. A closed series (a contour) is a smooth closed curve again (closedLinePath with smooth; before, 16 samples made a polygon). Markers on a line series: every sample up to 8 samples (PLOT_MARKER_ALL_MAX_SAMPLES, kept); a longer series marks only its first, last and labelled samples (the pre-sprint showPlotMarker rule; the 9-19 "every other sample" rule and the "line alone from 20" rule are gone, PLOT_MARKER_LINE_ONLY_FROM_SAMPLES is exported but no longer read). A closed series keeps its marker rule (labelled/id only). I did NOT build the earlier "discrete" idea (integer x, no function word): the references answer it, see below.

What the existing smooth path does with 9 samples: monotone cubic (Steffen limiter, plot-lines.js monotoneLinePath): it passes through every sample exactly; between samples it never overshoots, so every sample that is a local extremum has a horizontal tangent there (the Overfit curve's peaks at (0.5, 4) and (2.5, 9) and dips at (1.5, 1) and (3.5, 5) are the samples themselves, round, not cusps).

Held-out error vs tree depth: `ml-trees-depth-overfit` declares smooth: false on both series (Training, Held out; 8 samples each), so it stays straight with a marker on every sample: covered by the new rule, nothing to tell. The other held-out-error reference, `d2l-complexity-heldout-error` (model size 1-5, 5 samples) declares nothing and is a smooth curve with 5 markers again (before: straight).
