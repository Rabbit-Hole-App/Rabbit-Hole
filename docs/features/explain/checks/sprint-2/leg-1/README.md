# LEG-1 no legend pill for a one-series plot (ml-plot-layouts.js)

Rule: a coordinate-plot with ONE series draws no legend pill (the title and the axes name it); two or more series keep the pills (or, for 2-3 plain line series, the curve labels of PLT-3(A)). A series with a low/high interval used to say so in its pill ("· low/high interval"); on a one-series plot that note is gone too (the band itself shows it).

Files (408 and 720, before/after): bell, ml-zscore-distribution-tails, ml-trees-depth-overfit (two series: unchanged, the control).
