CROSS-FIELD MESSAGES of the six checkers (from the code; build-renderer-constraints.mjs buildConstraints() reused; token-links and part of flow attributed by reading the code):
- bar-chart: bars required for basic charts; a variant needs categories and series; grouped or stacked series need an explicit variant; no legacy bars in grouped variants; one value per category in each series; labels unique; a total belongs to one stacked bar; stacked parts positive; "the parts add up to X, not the stated total Y".
- coordinate-plot: points or compact samples; one x per y; a line needs 2 points, a closed line 3 distinct vertices; point outside axis bounds; max > min; log axes positive; integer ticks need linear integer bounds; step and uncertainty curves need strictly increasing x; uncertainty low <= y <= high; stem series need a linear y domain containing zero; sample ids unique per series; reference line within bounds; polygon nonzero area; segment or vector distinct endpoints; derive rules.
- token-links: an existing zero-based source index; a distinct source index per query; one weight per target token in order; weight at most 1 unless normalized; normalized weights have a positive total.
- heatmap: one cell per column in every row; highlight refers to an unknown cell; a masked cell cannot be highlighted; value outside the explicit range; range max > min; no range computable (masked or constant cells: write a range); contrast and diagonal arithmetic messages.
- matrix: cells equal columns; layout teaching for more than 5 columns or 6 rows, semantic styling or stable row ids; teaching rows need stable ids; emphasis references an existing row id and zero-based column.
- flow: unique node ids; edge refers to an unknown node; no self edge and no repeated directed pair; an outcome has no outgoing edges; a process at most one; a decision two or three with distinct non-empty labels; exactly one root; no cycle or unreachable node; a fork needs 2+ outgoing routes; a merge 2+ incoming and exactly one outgoing; highlightPath rules (no repeat, known nodes, follows edges, start to a terminal; two routes distinct, diverge at a fork, end together, reconverge at a merge); tensor: at most eight visible cells, one value per visible cell; a node needs a label or a tensor.
