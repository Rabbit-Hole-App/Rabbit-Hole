## Shared executable conventions

Use unflipped cross-correlation, bias0, dilation1:
Y[r,c,o] = sum over input channel i and spatial offsets a,b of X[r·sH+a−pTop,c·sW+b−pLeft,i]·K[o,i,a,b].
Output height is floor((H+pTop+pBottom−kH)/sH)+1, similarly for width. Add literal zeros only in named padding cases. There is no hidden kernel flip, ReLU, training result or performance claim.

The common K=[[1,−1],[0,2]] is shared by patch, channel0, padding and stride cases. Channel0's patch comes from the shared patch field. Window reuse counts position memberships, independent of intensities. Pointwise, stripes, pooling and motif detection have separate fixtures. Every product/output/map derives from actual operands and window enumeration. Exact halves/2.5 need no rounding; integral-valued floats can display as integers.

Required Standard operands/results are native numeric cells. Captions supply operations, dimensions, coordinates and rule context; they never replace absent kernels or numeric results. A block containing K/W is explicitly a supplied filtering/projection operator applied to its input, not coefficients generated from that input. Packed rows identify channel/filter/offset roles honestly. Tensors allow at most four rows/eight total cells; heatmaps6×6; native block-stacks2–6 blocks.
