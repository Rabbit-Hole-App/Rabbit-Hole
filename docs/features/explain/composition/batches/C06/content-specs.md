## Shared language data and arithmetic

One independent ordered output vocabulary: clouds, bring, rain, `<eos>`; stable slots0–3. `<bos>` is an input-only start marker, explicitly excluded from the output vocabulary. Observed sentence clouds bring rain yields four aligned examples: `<bos>`→clouds; `<bos> clouds`→bring; `<bos> clouds bring`→rain; `<bos> clouds bring rain`→`<eos>`. Compute every slot lookup, one-hot vector and prefix/target row from the same token identities/positions.

For selected observed target bring, two independently labelled illustrative logit cases A=(0,1,0,-1), B=(0,2,0,-1) share that vocabulary and true target. Stable softmax gives A target probability0.5344466453885229 and loss0.6265233750364458nats; B probability0.7573132023431749 and loss0.2779783695755581nats; delta B−A=−0.3485450054608875nats. These values were independently checked with ordinary exponential/log arithmetic. In implementation retain full precision, derive rounded display arrays/captions once, and verify the loss change from unrounded values; do not calculate it from rounded chart labels. These are chosen toy distributions, not observed training steps or an optimizer trajectory. Probabilities and losses require magnitude encodings; no numeric table masquerading as a probability distribution.

## ml-language-training-vocabulary-target-slots

The output vocabulary defines a fixed ordering of slots in the prediction vector. A one-hot target identifies the observed next token by marking only its vocabulary slot. Preserve an independent toy vocabulary, explicit indexed entries, the special stopping entry, a stable label-to-slot mapping, a chosen observed next token, one active target entry and zeros elsewhere. Overview is a deliberately small indexed teaching table showing the selected bring and stopping-entry slots, explicitly labelled as two selected entries of the four-slot vocabulary; it does not claim that omitted slots do not exist. Standard is one full-width four-row heatmap: every row label contains its stable slot and token, one target column marks bring and every other row is zero. The visible caption names the observed token and slot operation; useWhen alone is insufficient. Deep is one native four-row/two-column one-hot grid for bring versus the final `<eos>` target in the same fixed vocabulary order. Its implicit probe changes the observed token while the mapping remains fixed; each column still has exactly one active flag, expressed as the invariant sum over target slots equals one. The grid is an indicator encoding, not probability magnitude. No extra detail figure is required just to repeat the same vector. Preserve lesson08 for both Transformer32 and33.

Keywords: `indexed output slots`, `observed token indicator`. useWhen: show fixed indexed output-vocabulary identity plus the observed-token indicator, including stop; exclude generic feature one-hot encoding, arbitrary vocabulary reordering, model probability comparison and decoder generation.

## ml-language-training-target-probability-and-loss

Training compares the model's next-token distribution with the observed target token. Assigning greater probability to observed next tokens reduces their cross-entropy loss. Preserve complete predicted and one-hot target distributions in the same vocabulary order, the selected correct-token probability and negative-log loss, and two independently labelled illustrative model distributions with the same vocabulary/true target and exact loss change. Overview is one native four-bar model distribution for selected observed bring, with visible illustrative marker and target/loss context. Standard is a full-width native grouped bar chart: four vocabulary categories, model A probabilities and the one-hot observed target as two labelled series. Its caption names target bring, model target probability and its computed negative natural-log loss. Deep is a full-width grouped probability chart with the same four categories and three labelled series: illustrative model A, illustrative model B, observed one-hot target. This is within the existing three-series schema. Its separate Deep detail uses two loss-magnitude bars in nats, with exact computed rounded B−A change and the negative-log relationship visible. The implicit probe raises only bring's raw logit before renormalization; both full distributions are recalculated, all candidate probabilities still sum to one, the target stays fixed and loss falls. Do not imply that both model distributions have a one-hot shape or that the one-hot series is itself a model prediction. Preserve representative/alias lessons03/09 for Transformer34 and36.

Keywords: `paired token distributions`, `illustrative distribution losses`. useWhen: compare full same-order vocabulary probabilities against a fixed observed target and illustrative loss cases; exclude generic binary-crossentropy curves, only two loss bars, measured optimizer steps or sampling/greedy generation.

## ml-language-training-prefix-target-alignment

A target sentence supplies a different next-token label at each prefix position during training. A next-token training example aligns each prefix with its immediate continuation. A causal language model learns by predicting each next token from earlier tokens. Preserve overlapping prefixes from one independently written sentence, one immediate observed target per position, the stop target, no information beyond the target boundary and a visible separation between pretraining token labels and downstream task class labels. Overview is a two-row observed-prefix/next-target teaching matrix. Standard is the full four-row native matrix with stable position identity, all observed prefixes and their immediate target including `<eos>`; its visible caption states that these are observed token targets rather than downstream class labels or generated feedback. Deep retains the full-width observed-prefix/target matrix and makes the causal conditional on earlier observed positions explicit in its visible caption. Position-based causality matters even when token strings repeat. Its separate Deep detail is the recomputed observed-prefix/target table after replacing only the final rain token by clouds, which remains in the declared vocabulary. Earlier unchanged prefix/label rows stay unchanged; the immediately preceding target and later prefix change. The probe asserts position/text-row invariance, not a guarantee about cached states or every real model implementation. New family lesson union01/03/15 is confined to this family; representative Transformer35 remains01/03 and both GPT2-36 and BERT20 aliases remain01/15.

Keywords: `observed prefix labels`, `training continuation rows`. useWhen: align overlapping observed training prefixes with immediate token labels and a stop marker; exclude generated-token feedback, fixed word2vec windows, recurrent state mechanisms, masked-token recovery or downstream class labels.

## ml-summarization-supervised-summary-pair

A document and its lead summary can provide a paired example for supervised summarization. Preserve independently authored short source body and supplied lead, separate source/target fields, stable record identity and a clear boundary before task markers/model-input formatting. Use two entirely toy records, e.g. body “Volunteers opened a food pantry.” / supplied lead “A volunteer food pantry opens.” and body “Snow closed the road; crews cleared it.” / supplied lead “Crews cleared a snowbound road.” These are authored text examples, not real events or generated summaries; all entire fields fit the native40-character matrix-cell limit without truncation. Overview is one raw pair as two field rows (source body versus supplied target lead) in a native matrix. Standard is two paired records in a full-width teaching matrix with columns record identity, source body, supplied lead; row position and record identity are distinct so the Deep reorder remains meaningful. Its caption explicitly says these are raw supervised fields before model-input formatting. Deep reorders both records and field presentation using keys, preserving each body↔lead association; a visible pair-identity formula states the implicit invariant, rather than inventing a quality score or data quantity. An optional separate extra is unnecessary if the one Deep matrix already supplies the computed reorder probe. Do not turn this into a generation workflow, task-marker example, classifier labels or a supplied-target-as-inference-input claim. Preserve GPT2-60 lesson01.

Keywords: `raw summarization pairs`, `body lead supervision`. useWhen: show independently written source-body/supplied-lead raw supervised pairs before formatting; exclude GPT2 task separators, translation, generated outputs, summary-quality scores or a complete summarization model.

## Expressibility and honest boundaries

The full approved source points are expressible using existing native kinds. The initially proposed4×4 causal mask has a native minimum444px at requested408, so use the actual prefix/target text rows and conditional plus a later-token perturbation, rather than treating a dense availability grid as a source requirement. Grouped probability bars have the existing native minimum420px, documented separately from requested408; this small width difference must pass actual visual readability rather than being hidden as exact408 fit. No unsupported transpose mode exists for grouped bars. No current requirement needs unsupported composition or a text-box workaround. Grouped bars are supported (four shared categories, up to three series); loss and probability units must use separate full-width figures. Summary bodies are deliberately independently authored short complete text, not silent truncation of longer source prose; text records belong in teaching tables. Native matrix requires at least two rows, handled by one pair's source/target field rows on Overview, and two keyed records on Standard. A literal embedded inset, arbitrary multi-figure layout or annotated arrow is not required by these eight briefs. Exact whole Transformer/GPT2/BERT original figures, measured training improvements, downstream representation guarantees and real-corpus claims remain outside this toy content coverage.
