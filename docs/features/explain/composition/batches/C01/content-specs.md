## ml-regularization-regularized-objective

A computation graph shows which intermediate values, weights and targets determine the data loss and the regularized objective: keep the feature-to-prediction chain, target input to loss and weight-to-penalty branch separate; combine data loss and penalty only at the objective. [Source: d2l-backprop Figure 01](../../../../explain-on-canvas/handoff/figure-briefs/d2l-backprop/briefs.md#figure-01). Overview shows the two final objective results, `2.5` without the penalty and `3.5` with it, before expanding the arithmetic. Standard exposes the independent data-loss and weight-penalty inputs: mean squared error `2.5`, squared-weight sum `5`, strength `0.2`, penalty `1`, total `3.5`; the bias is not penalized. Dependency labels stay symbolic and numeric terms use magnitudes and a stacked whole. Deep doubles the strength to `0.4` with predictions and weights held fixed: loss remains `2.5`, penalty becomes `2`, and total becomes `4.5`. This evaluates an objective, not a training-update loop. Preserve lessons `02, 10`.

## ml-regularization-dropout-mask

Training-time dropout temporarily disables some hidden activations and their paths while retaining the full network for inference: the same small network before and after one sampled mask, with the disabled unit distinguished and the weights not permanently removed. [Source: d2l-dropout Figure 01](../../../../explain-on-canvas/handoff/figure-briefs/d2l-dropout/briefs.md#figure-01). Overview treats hidden activations `(3,1)` as the given input to a temporary mask and shows `(3,0)` for that pass. Standard adds inverted-dropout scaling: the kept activation is divided by keep probability `0.5`, giving `(6,0)`; feature identities stay identical across panels. Deep adds the exact linear-readout check over all four equally likely masks: predictions `1,7,5,11` average to the unmasked inference prediction `6`. Name this linear-readout condition explicitly. Masked values are shown by zero magnitude; native per-neuron greying, if unavailable in the permitted child kinds, is recorded as an expressibility limit rather than invented through unsupported fields.
