## Shared part opportunities exposed by the cards

- Linked geometry and rule data: predicate trees, leaf regions, active routes and point probes. A control can change several bound views at once.
- Ordered/discrete observations: candidate thresholds, tree depths, forest sizes and alpha paths need exact supplied domains, meaningful log axes, linked comparison values and optional best-setting selection.
- Membership and sampling: row banks, repeated copies, sample prefixes, multiplicity, OOB trays, class buckets and vote accumulation share data operations. Their bindings are richer than scalar formula roles.
- Numerical reasoning: weighted contributions, exact fractions, normalization, probability products, leaf means, rounding and residuals can reuse a ledger/readout vocabulary with declared units and denominators.
- Comparison semantics: analytic vs illustrative vs worked data, raw vs normalized measures, realized vs expected samples, and supplied vs changed experiments must remain explicit.
- The useful missing unit is usually a bound part or a linked composition. The descriptive mechanism names here are not a requirement to implement one runtime family per prompt.
