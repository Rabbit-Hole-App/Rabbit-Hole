## Runtime and production-enablement gates

- Cloudflare rejected the attempted Dynamic Workers loader deployment: `In order to use Dynamic Workers, you must switch to a paid plan` (10195), recorded in ctrlk-source-derivative-deploy.log:154. The build manifest explicitly records baseline config deployed with loader absent. A disabled local evidence/wrangler.ctrlk-pilot.jsonc.disabled preserving INLINE_CODE_ENABLED=true is not a successful deployment or active service.
- JavaScript admission requires INLINE_CODE_ENABLED=true, INLINE_CODE_LOADER.load, and positive integer-string INLINE_CODE_MAX_RUNS, INLINE_CODE_MAX_MICROS, INLINE_CODE_RESERVE_MICROS (reserve<=max). Admission defaults off. Started unknown outcomes retain reservations; no retry/refund claim. Status/cancel remain for existing jobs. No live production secrets or binding state was queried by this read-only audit.
- Image admission requires INLINE_IMAGE_EDIT_ENABLED=true, server OPENAI_API_KEY and finite positive INLINE_IMAGE_EDIT_RESERVED_USD; client consent maximum must cover configured reservation. Pinned adapter model is gpt-image-2.5-sunburst-2026-09-08. No automatic retry/fallback. Real provider cost is not certified from a reservation/estimate. Existing 24-hour spend ledger is not a new monthly image budget.
- Deploying code does not establish either runtime/provider is enabled. Keep flags disabled unless separately authorized/configured/qualified. CAD budgets, successful CAD calls and infrastructure do not establish Ctrl+K authorization or verification.
- Earlier failed source/derivative and replacement runs remain attributed individually in the expanded receipt. Source run4 passed5/5; recognized-plot run2 passed6/6; all six distinct replacement cases passed across runs2/4/5.
