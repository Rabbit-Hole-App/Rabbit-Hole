# CI Speed Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Routine pushes get a browser-check verdict in a target of 4-6 minutes, and the complete release gate finishes in a target of 12-15 minutes. Both are measured before and after on the same candidate. The release gate stays the deployment requirement.

**Architecture:** Two parts on two branches.
- **Part A (harness branch `parallel/gate-sharded-next`, from 947f818a)** makes the existing Windows release gate faster:
  - measure first;
  - delete duplicate runs, recording each one;
  - stop rebuilding a bundle a part already built;
  - move the verify wait off the critical path;
  - re-pack shards by measured duration;
  - aggregate the newest attempt per part;
  - retry only a recognized transient, and only for a check proven to be retry-safe.
- **Part B (app branch `infra/ci-fast`, from main)** adds a Linux fast tier: map-based selection, a static matrix where each job selects and builds for itself, and cancellation of superseded runs.

**Tech Stack:**
- GitHub Actions (windows-2022, ubuntu-latest);
- Node 24 ES modules with `node:test`;
- Git Bash shell scripts in the gate;
- wrangler dev (4.150.0) and Playwright Chromium for the checks.

**Spec:** `docs/superpowers/specs/2026-10-13-ci-fast-and-reliable-design.md` (9f6983b8), with the owner's corrections of 2026-10-13 (listed under Global Constraints, which take precedence where they differ).

## Global Constraints

- The release gate (`gate-sharded.yml` plus `refs/notes/gates`) stays the only evidence `deploy-dev.yml` accepts. No change in this plan weakens it, and every logical test it runs today still runs.
- Speed only:
  - no production-settings validation;
  - no reporting infrastructure beyond `timing.mjs`;
  - no unrelated cleanup.
- Workflow-file pushes are made by the owner with a `!` command. Task steps that push a workflow file end with the exact command for the owner.
- Targets are 4-6 min (fast tier) and 12-15 min (release gate) until demonstrated by the measurements in Tasks A1, A9 and B6.
- Every job has a deterministic install fallback. A cache miss changes speed only, never what runs: `npm ci` from the lockfile and `npx playwright install chromium` always run, and the caches only make them faster.
- `needs:` serializes jobs. The plans below use `needs:` only where an output is required, and never poll for artifacts.
- A retry happens only for a recognized transient on a retry-safe check. The first attempt's evidence is kept. A pass after a retry is reported as such, never as a clean pass.
- Selection compares against the newest fast-tier run that passed on an ancestor of HEAD, so earlier untested pushes on the branch are included. It covers renamed and deleted paths.
- Removing a duplicate execution needs proof that the remaining execution covers the same logical test (the same check file, the same stack configuration, the same preceding state). Each removed duplicate is recorded in `scripts/r36-gate/README.md`.
- Commits:
  - no double quotes in commit messages;
  - no Co-Authored-By or any other attribution trailer;
  - use `git commit --only <paths>`.
- Times shown to the owner are in PT.

## Review Focus

1. **A rename-only push**, with the content unchanged. Selection must include the checks for both the old and the new path. Test in Task B2.
2. **A force-pushed branch** whose last green fast run is no longer an ancestor of HEAD. The baseline falls back to the merge-base with main, never to the previous push alone. Test in Task B2.
3. **A failed-only gate rerun whose rerun job is cancelled.** The gate fails, and never reuses the older passing attempt of that part. Test in Task A7.
4. **A worker crash caused by an application regression** (an uncaught exception, with "Network connection lost" as a side effect). It is not a recognized transient, so it is not retried. More than 2 qualified retries in one gate fail the gate as instability. Test in Task A8.
5. **A cold cache** (new lockfile, empty Playwright cache). Every selected check still runs, just slower. Measured in Task B6 as its own row; the install steps are unconditional (Task B3 test).

```js
// scripts/r36-gate/timing.mjs
// Measures one gate run attempt from the GitHub job records and, when given, its artifacts' per-process receipts.
// Queue time (created -> started) is reported apart from runner time. A step that only waits (the verify wait) is
// runner time too: the runner is held while it waits.
import { execFileSync } from 'node:child_process';
import { readdirSync, readFileSync, statSync } from 'node:fs';
import { join, basename } from 'node:path';
const t = s => Date.parse(s), min = ms => Math.round(ms / 600) / 100;
const IDLE = /^Wait for /;
export function summarizeRun(run, jobs) {
  const ran = jobs.filter(j => j.started_at && j.completed_at);
  const rows = ran.map(j => {
    const steps = (j.steps || []).filter(s => s.started_at && s.completed_at).map(s => ({ name: s.name, min: min(t(s.completed_at) - t(s.started_at)) }));
    return { name: j.name, queueMin: min(t(j.started_at) - t(j.created_at)), runMin: min(t(j.completed_at) - t(j.started_at)),
      idleMin: steps.filter(s => IDLE.test(s.name)).reduce((a, s) => a + s.min, 0), steps };
  });
  const firstStart = Math.min(...ran.map(j => t(j.started_at))), lastEnd = Math.max(...ran.map(j => t(j.completed_at)));
  return { runId: run.id, attempt: run.run_attempt, queueMin: min(firstStart - t(run.created_at)), wallMin: min(lastEnd - t(run.created_at)),
    runnerMin: Math.round(rows.reduce((a, r) => a + r.runMin, 0) * 100) / 100, jobs: rows };
}
export function stageDurations(files) {
  const by = new Map();
  for (const { name, json } of files) {
    const m = name.match(/^process-(.+?)-\d{10,}-\d+\.(start|exit)\.json$/); if (!m) continue;
    const key = name.replace(/\.(start|exit)\.json$/, ''); const e = by.get(key) || { check: m[1] }; e[m[2]] = json.at; by.set(key, e);
  }
  return [...by.values()].filter(e => e.start && e.exit).sort((a, b) => t(a.start) - t(b.start))
    .map(e => ({ check: e.check, min: min(t(e.exit) - t(e.start)), started: e.start }));
}
const walk = d => readdirSync(d).flatMap(n => { const p = join(d, n); return statSync(p).isDirectory() ? walk(p) : [p]; });
if (process.argv[1] && basename(process.argv[1]) === 'timing.mjs') {
  const [id, attempt = '1'] = process.argv.slice(2).filter(a => !a.startsWith('--'));
  const gh = path => JSON.parse(execFileSync('gh', ['api', path], { encoding: 'utf8' }));
  const repo = 'repos/Rabbit-Hole-App/Rabbit-Hole/actions/runs/' + id;
  const run = gh(`${repo}/attempts/${attempt}`), jobs = gh(`${repo}/attempts/${attempt}/jobs?per_page=100`).jobs;
  const out = summarizeRun(run, jobs);
  const i = process.argv.indexOf('--artifacts');
  if (i > 0) out.stages = stageDurations(walk(process.argv[i + 1]).filter(p => /\.(start|exit)\.json$/.test(p)).map(p => ({ name: basename(p), json: JSON.parse(readFileSync(p, 'utf8')) })));
  console.log(JSON.stringify(out, null, 2));
}
```

```js
// A stage run by two parts on the same stack script and preceding section is a duplicate execution.
import { UNIT_STAGES } from './shards.mjs';
export function inventory(int35, focused, shards) {
  const rows = new Map();
  for (const m of int35.matchAll(/^run (stack(?:-app)?\.sh) (\S+) (\S+)$/gm)) rows.set(m[2], { stage: m[2], check: m[3], stack: m[1], parts: [] });

    if (!rows.has(s)) rows.set(s, { stage: s, check: null, stack: null, parts: [] });
  shards.forEach((stages, k) => stages.forEach(s => rows.get(s)?.parts.push(`shard-${k + 1}`)));
  if (!shards.flat().includes(UNIT_STAGES[0])) UNIT_STAGES.forEach(s => rows.get(s).parts.push('units'));

  return [...rows.values()];
}
```

```js
// The same-sha canonical verify.yml run must have succeeded (the protection each run job used to wait for).
import { execFileSync } from 'node:child_process';
export function verifyVerdict(runs, sha) {
  const mine = runs.filter(r => r.headSha === sha);
```

```js
// scripts/r36-gate/pack.mjs
// Assigns the gate's browser stages to K shards by measured median minutes (durations.json), longest unit first onto
// the cheapest shard. A shard pays STACK_MIN for each stack section it has to start (build-once still builds per flavor).
import { ORDER, UNIT_STAGES } from './shards.mjs';
export const STACK_MIN = { app: 1.6, dev: 1.6, prod: 1.6, journey: 1.6 };
export const UNITS = [['rh-app', 'comments', 'comments-invite', 'explore'], ['bundle(dist)', 'bundle(dist-dev)'],
  ['journey J1-J8', 'tutor-slice', 'blank-hooks', 'practice-card', 'canvas-chrome']];
const section = s => s === 'rh-app' || s === 'comments' || s === 'comments-invite' ? 'app' : s.startsWith('bundle(') ? 'prod'
  : ['journey J1-J8', 'tutor-slice', 'blank-hooks', 'practice-card', 'canvas-chrome'].includes(s) ? 'journey' : 'dev';
export const cost = (stages, d) => stages.reduce((a, s) => a + (d[s] ?? 0.5), 0)
  + [...new Set(stages.map(section))].reduce((a, k) => a + STACK_MIN[k], 0);
export function pack(d, k) {
  const browser = ORDER.filter(s => !UNIT_STAGES.includes(s));
  const grouped = new Set(UNITS.flat());
  const units = [...UNITS, ...browser.filter(s => !grouped.has(s)).map(s => [s])];
  units.sort((a, b) => cost(b, d) - cost(a, d) || ORDER.indexOf(a[0]) - ORDER.indexOf(b[0]));
  const shards = Array.from({ length: k }, () => []);
  for (const u of units) {
    const i = shards.map((sh, j) => [cost([...sh, ...u], d), j]).sort((a, b) => a[0] - b[0] || a[1] - b[1])[0][1];
    shards[i].push(...u);
  }
  return shards.map(sh => sh.sort((a, b) => ORDER.indexOf(a) - ORDER.indexOf(b)));
}
```

```js
// scripts/r36-gate/attempts.mjs
// For one workflow run and one candidate: each required part's newest attempt that actually ran. A part's newest
// attempt decides it - an older pass never stands in for a newer failure or cancellation.
import { execFileSync } from 'node:child_process';
export function pickAttempts(jobs, parts) {
  const attempts = {}, errors = [];
  for (const part of parts) {
    const mine = jobs.filter(j => j.part === part).sort((a, b) => b.runAttempt - a.runAttempt);
    if (!mine.length) { errors.push(`${part}: no job`); continue; }
    attempts[part] = mine[0].runAttempt;
    if (mine[0].conclusion !== 'success') errors.push(`${part}: newest attempt ${mine[0].runAttempt} ${mine[0].conclusion}`);
  }
  return { attempts, errors };
}
export function runJobs() {

  const jobs = JSON.parse(execFileSync('gh', ['api', `repos/${repo}/actions/runs/${id}/attempts/${n}/jobs?per_page=100`], { encoding: 'utf8' })).jobs;
  return jobs.map(j => ({ part: j.name.match(/^run \((.+)\)$/)?.[1], runAttempt: j.run_attempt, conclusion: j.conclusion })).filter(j => j.part);
}
```

```js
// scripts/r36-gate/templates/classify-retry.mjs
// One retry, only for the recognized local-runtime transient, only for a check proven retry-safe (transients.json).
import { readFileSync, readdirSync, existsSync } from 'node:fs';
import { join, basename } from 'node:path';
export function classifyRetry({ name, exitCode, stackAlive, checkLog, appLog, wranglerLogs, retrySafe, transients, workerErrors, retriesUsed, maxRetries = 2 }) {
  if (exitCode === 0) return { retry: false, reason: 'passed' };
  if (stackAlive) return { retry: false, reason: 'failed with the stack alive' };
  if (/✗|AssertionError|^not ok|^FAIL/m.test(checkLog)) return { retry: false, reason: 'assertion failure before the stack died' };
  if (workerErrors.some(e => appLog.includes(e))) return { retry: false, reason: 'worker exception in the app log' };
  const hit = transients.find(t => wranglerLogs.some(l => t.all.every(s => l.includes(s))));
  if (!hit) return { retry: false, reason: 'stack died without a recognized transient signature' };
  if (!retrySafe[name]) return { retry: false, reason: `${name} is not proven retry-safe` };
  if (retriesUsed >= maxRetries) return { retry: false, reason: `retry budget of ${maxRetries} used in this part` };
  return { retry: true, reason: hit.id };
}
if (process.argv[1] && basename(process.argv[1]) === 'classify-retry.mjs') {
  const [name, exit, alive, checkLogPath, stackDir, used] = process.argv.slice(2);
  const cfg = JSON.parse(readFileSync(new URL('./transients.json', import.meta.url), 'utf8'));
  const read = p => (existsSync(p) ? readFileSync(p, 'utf8') : '');
  const logs = join(stackDir, 'wrangler-logs');
  const r = classifyRetry({ name, exitCode: Number(exit), stackAlive: alive === '1', checkLog: read(checkLogPath), appLog: read(join(stackDir, 'app.log')) + read(join(stackDir, 'cp.log')),
    wranglerLogs: existsSync(logs) ? readdirSync(logs).map(f => read(join(logs, f))) : [], retrySafe: cfg.retrySafe, transients: cfg.transients, workerErrors: cfg.workerErrors,
    retriesUsed: Number(used), maxRetries: cfg.maxRetriesPerPart });
  console.log(`${r.retry ? 'retry' : 'fail'} ${r.reason}`);
}
```

```js
// scripts/ci/affected.mjs - fast-tier selection. Compares HEAD with the newest green fast-tier run that is an ancestor
// (so pushes whose runs were cancelled are included), or the merge-base with main. Renames count both paths, deletes
// count the old path. An executable path with no class fails selection; it is never silently skipped.
import { execFileSync } from 'node:child_process';
import { readFileSync } from 'node:fs';
import { basename } from 'node:path';
// Tokenized so an inserted `.*` is never rewritten by a later replacement.
const rx = g => new RegExp('^' + g.split(/(\*\*\/|\*\*|\*)/).map(t => t === '**/' ? '(?:.*/)?' : t === '**' ? '.*' : t === '*' ? '[^/]*'
  : t.replace(/[.+?^${}()|[\]\\]/g, '\\$&')).join('') + '$');
const any = (globs, p) => globs.some(g => rx(g).test(p));
export function classify(p, map) {
  if (any(map.docs, p)) return 'docs';
  if (any(map.broad, p)) return 'broad';
  if (Object.keys(map.mapped).some(g => rx(g).test(p)) || /^packages\/web\/e2e\/[^/]+-check\.mjs$/.test(p)) return 'mapped';
  if (any(map.none, p)) return 'none';
  return any(map.executable, p) ? 'unmapped' : 'none';
}
export function select(changes, map) {
  const linux = Object.keys(map.checks).filter(c => map.checks[c].runner !== 'windows-only');
  const checks = new Set(), reasons = [], unmapped = []; let broad = false;
  for (const c of changes) for (const p of [c.path, c.oldPath].filter(Boolean)) {
    const k = classify(p, map);
    if (k === 'broad') { broad = true; reasons.push(`${p}: broad`); }
    else if (k === 'unmapped') unmapped.push(p);
    else if (k === 'mapped') {
      const own = /^packages\/web\/e2e\/([^/]+-check\.mjs)$/.exec(p)?.[1];
      const hits = own ? [own] : Object.entries(map.mapped).filter(([g]) => rx(g).test(p)).flatMap(([, v]) => v);
      for (const h of hits) { checks.add(h); reasons.push(`${h}: ${p}`); }
    }
  }
  if (broad) linux.forEach(c => checks.add(c));
  return { checks: [...checks].filter(c => map.checks[c]?.runner !== 'windows-only').sort(), reasons, unmapped, broad,
    notCovered: [...checks, ...(broad ? Object.keys(map.checks) : [])].filter(c => map.checks[c]?.runner === 'windows-only').filter((c, i, a) => a.indexOf(c) === i) };
}
export function baseline({ head, greenShas, isAncestor, mergeBaseMain }) {
  return greenShas.find(s => s !== head && isAncestor(s, head)) ?? mergeBaseMain;
}
export function parts(checks, map, n) {
  const out = Array.from({ length: n }, () => []), load = Array(n).fill(0);
  for (const c of [...checks].sort((a, b) => (map.checks[b]?.seconds ?? 60) - (map.checks[a]?.seconds ?? 60) || a.localeCompare(b))) {
    const i = load.indexOf(Math.min(...load)); out[i].push(c); load[i] += map.checks[c]?.seconds ?? 60;
  }
  return out;
}
if (process.argv[1] && basename(process.argv[1]) === 'affected.mjs') {
```

```bash
#!/usr/bin/env bash
# run-part.sh <sel.json> <out-dir>: this part's fast-tier checks, one at a time, gate-format exit lines, no retry.
set -uo pipefail
SEL=$1; OUT=$2; W=$(git rev-parse --show-toplevel); mkdir -p "$OUT"
mapfile -t CHECKS < <(node -p 'require(process.argv[1]).checks.join("\n")' "$SEL")
NEEDS_FORK=$(node -e 'const m=require(process.argv[2]+"/scripts/ci/check-map.json");const s=require(process.argv[1]);process.stdout.write(s.checks.some(c=>m.checks[c].runner==="fork")?"1":"0")' "$SEL" "$W")
if [ "$NEEDS_FORK" = 1 ]; then bash "$W/scripts/ci/stack.sh" start "$OUT/stack" || { echo 'stack failed'; exit 1; }; fi
E="BASE=http://127.0.0.1:8878 SMALL_CP=http://127.0.0.1:8879 PERSIST=$OUT/stack/local D1_CONFIG=$OUT/stack/integ-local-cp.jsonc"
FAIL=0
for C in "${CHECKS[@]}"; do
  L="$OUT/${C%.mjs}.log"; T0=$(date +%s)
  (cd "$W/packages/web" && env $E timeout 900 node "e2e/$C" "$OUT/${C%.mjs}-shots" > "$L" 2>&1); rc=$?
  N=$(sed 's/\x1b\[[0-9;]*m//g' "$L" | grep -aoE '[0-9]+/[0-9]+ checks passed' | tail -1)
  echo "${C%-check.mjs} exit $rc  ${N:-see log}  ($(( $(date +%s) - T0 ))s)" | tee -a "$OUT/fast.log"
  [ $rc = 0 ] || FAIL=1
done
[ "$NEEDS_FORK" = 1 ] && bash "$W/scripts/ci/stack.sh" stop "$OUT/stack"
node -p '"Not covered in this tier (release gate only): "+(require(process.argv[1]).notCovered.join(", ")||"none")' "$SEL" >> "${GITHUB_STEP_SUMMARY:-/dev/null}"
exit $FAIL
```
