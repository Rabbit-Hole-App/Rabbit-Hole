Why trees, and what a tree actually does

From root to leaf

Start at the root, the tree’s first question. Each question tests one feature and sends the case down a branch. Stop at a leaf to get the prediction. You can explain that prediction by tracing the tests along its path.

How the tree learns

During training, the tree tries questions such as “Age under 25?” and “Age under 30?” It chooses a split that groups examples with more similar outcomes, then repeats the process within those groups.

Approve or deny?

Age 25 · income $60k · credit score 640

  • Age under 30? Yes → check income. No → check credit score.
  • Income over $50k? Yes → Approve. No → Deny.

Prediction Approve. Both answers are yes, so this path reaches the Approve leaf without checking credit score.
