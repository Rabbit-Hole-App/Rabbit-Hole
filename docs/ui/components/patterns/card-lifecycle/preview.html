Decision Trees.md

Decision trees & random forests

A decision tree turns a prediction problem into a series of simple questions. Each question divides the examples into smaller groups.

How a split is chosen

A split is useful when it creates child groups that are more homogeneous than the parent group.

The tree compares candidate features and thresholds, then chooses the split that most reduces impurity. This process repeats until a stopping rule is reached.

Why use a forest?

A single tree can change a lot when its training examples change. A forest combines trees trained with randomness, reducing the variance of their combined prediction.

Feature importance

Importance describes how a model used its inputs. It does not establish that a feature causes an outcome.
