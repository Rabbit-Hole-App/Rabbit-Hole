Exact card design values

Blue is the primary UI color for actions, controls, selection, focus and playback. Use #375D92 for primary fill or selected ink, with #EAF1FB / #ADC4E5 for soft selection. Claude red (#934723 / #F8ECE3) is secondary, for Interactive identity and scene data accents. Both mode pills are text-only. Green is a status color for positive outcomes and completion.

Use these values for both card variants. The preview reads the same named CSS tokens. The font stack is Inter, Liberation Sans, Arial, sans-serif with pixel equivalents based on a 16 px root size. Line heights below are multipliers.
