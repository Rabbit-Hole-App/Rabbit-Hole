primary

One per surface. Solid accent. ui.jsx: <Button variant="primary">

secondary

Default pressable action. White + border + faint shadow so it reads as a button at rest. ui.jsx: variant="secondary"

soft

Feature call-to-action that should not shout (Connect Slack, Copy link). ui.jsx: variant="soft"

link

Blue text navigation, arrow when it leaves the page. ui.jsx: variant="accent"

split

Primary with an attached chevron menu. ui.jsx: <SplitButton onClick menu=[...]>
