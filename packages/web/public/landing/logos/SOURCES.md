# Landing logo sources

The owner's final twelve (2026-10-28), in order. Files retrieved 2026-10-28, never redrawn, traced or recoloured; the uniform gray is CSS only (`logos.css`). Source order used: (1) the organisation's official brand download, (2) an official asset served from the organisation's own site, (3) only where nothing official could be fetched, the Wikimedia Commons vector. Entries marked **NON-OFFICIAL COPY** are the third kind; the integrator should report them.
