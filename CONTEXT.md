# Rabbit Hole

A learning workspace where a learner explores a topic or a code repository on an infinite canvas, guided by a Tutor that plans, explains and checks understanding. Learners keep their work in a Library and can publish it for others to read, ask about and fork.

## Workspace

**Canvas**:
An infinite board that holds a learner's cards, shapes, drawings and conversations about one topic.
_Avoid_: Board (in user-facing copy), page, document

**Card**:
One self-contained unit of learning content placed on a canvas, such as an explanation, a quiz, code, an image or an equation.
_Avoid_: Block (in user-facing copy), node, tile

**Project**:
A group of canvases that learn from one code repository; it has its own display name, and the repository stays as its provenance.
_Avoid_: Repo canvas, workspace

**Rabbit Hole**:
A canvas nested under a card (or group) of another canvas, opened to go deeper on that one idea.
_Avoid_: Dive, sub-canvas, child board

**Pending hole**:
A Rabbit Hole that has been opened but holds nothing yet; it is not kept until something is placed in it.
_Avoid_: Draft hole, empty hole

**Rabbit Holes Map**:
The tree of a canvas's Rabbit Holes, used to see where you are and move between levels.
_Avoid_: Navigator, dive tree

**Library**:
The owner's own collection of canvases and projects.
_Avoid_: My files, dashboard

**Folder**:
A private, flat grouping inside the Library; an item sits in at most one folder.
_Avoid_: Collection, tag, space

## Publishing and readers

**Explore**:
The public listing where published work is found.
_Avoid_: Gallery, feed

**Creator**:
A person whose published work appears on Explore, identified by their handle.
_Avoid_: Author, publisher

**Reader**:
Anyone opening someone else's shared or published canvas without owning it.
_Avoid_: Viewer, visitor

**Fork**:
A reader's own independent copy of a shared or published canvas; it never changes when the original does.
_Avoid_: Clone, duplicate (Duplicate is the owner copying their own canvas)

**Comment thread**:
A conversation anchored to one object on a canvas, shown as a pin beside that object.
_Avoid_: Note, annotation

## Learning progress

**Claim**:
One statement a learner is meant to come to understand.
_Avoid_: Concept, objective, learning goal

**Idea**:
One distinct part of a claim that must be shown separately.
_Avoid_: Sub-claim, point

**Evidence**:
A recorded observation of what a learner showed about an idea or claim, as a pass or a fail.
_Avoid_: Score, grade

**Current evidence**:
The latest settled evidence for each idea; a later fail overrides an earlier pass.
_Avoid_: Best evidence, any pass

**Contested**:
An idea whose evidence shows the learner both stating it and contradicting it; it never counts as a pass.
_Avoid_: Mixed, partial

**Understood**:
A claim whose every idea currently passes, plus a transfer pass with no later negative.
_Avoid_: Mastered, done, completed

**Section**:
One stage of a learning path, with its own completion evidence.
_Avoid_: Step, chapter, module

**Completed**:
A section whose completion evidence holds on current evidence.
_Avoid_: Done, finished, understood

**Skipped**:
A section the learner moved on from before its completion evidence held; it says nothing about understanding.
_Avoid_: Passed, completed

## Evaluation

**Execution**:
One uniquely identified run of the Tutor evaluation harness, with its artifacts and outcome.
_Avoid_: Run (as an identifier); the date label is display only

**Analysis version**:
The version of the aggregation code that produced an aggregate; recomputed aggregates sit beside the original, never replace it.
_Avoid_: Revision, recompute
