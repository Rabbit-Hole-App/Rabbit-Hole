## Why this project, and why it is the first real external benchmark

It is MIT-licensed, which matters: reference material captured from it can live
in a commercial repository without a NonCommercial or ShareAlike problem. The
same is not true of every good explainer — Jay Alammar's posts are CC BY-NC-SA,
so The Illustrated Transformer can inform a reconstruction but its artwork
cannot be captured here.

It is also genuinely interactive and runs a real GPT-2, so the reference states
are a running system rather than a drawing of one.

## Attribution

Reference captures in each case's `reference/` are screenshots of the Transformer
Explainer interface, used to benchmark whether our own visual language can teach
the same mechanisms. They are not redistributed as a product, are not modified to

Models. https://poloclub.github.io/transformer-explainer/

## What is benchmarked

Not appearance. The question is whether our visual language can teach the same
mechanisms with comparable clarity, using only its own vocabulary. Every case
here keeps `visualImitationTarget: false`.
