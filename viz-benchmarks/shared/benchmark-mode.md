# Benchmark Mode

External reference material is visible to the benchmark-generation and critic workflow.

The target is semantic / pedagogical parity, not visual copying.

Score:
- correctness
- concept coverage
- hierarchy
- readability
- spatial relationships
- progressive disclosure
- interaction/motion capability
- generic composition

Do not score:
- exact palette
- exact typography
- exact shape language
- exact arrows
- exact wording
- exact coordinates
- decorative imitation
