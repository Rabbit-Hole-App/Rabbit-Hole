# counter

> Generated by `small` from the code — regenerated on every deploy.

## What it does

A shared click counter. One page shows the count; the button adds one. The count
lives in SQLite on the app's persistent volume, so it survives redeploys.

## Who it's for

Anyone on the team who wants a number everyone can bump — demos, tally counts,
standup ice-breakers.

## How to run it locally

```
pip install -r requirements.txt
flask --app app run
```

Without the platform volume, the database falls back to `./counter.db` in the
current directory.

## What it needs

| Secret | Used in | For |
|---|---|---|
| SMALL_DATA (set by the platform) | app.py:10 | directory holding `counter.db`, the SQLite database |

## Files

| File | Role |

## Commands

| What | Command |
|---|---|

## Endpoints

| Route | What it does |
|---|---|
| `GET /` | show the current count |
| `POST /inc` | add one, redirect back |

## What it talks to

Nothing outside the machine — only its own SQLite file under `SMALL_DATA`.

## Known limits

One connection per request, no WAL — fine at internal-tool traffic, not built
for concurrency-heavy use.

## If it breaks

| Symptom | Likely cause | Where to look |
|---|---|---|
| Count resets after deploy | `[storage]` missing from small.toml, no volume mounted | small.toml, `small deploy` output |
| 500 on any page | database file unwritable | app.py:10, `small logs` |
